# 領地租賃（子領地分租）設計草案

目標：領地擁有者（或國庫）把自己的一塊領地切成子領地，出租給其他玩家；承租期間承租人有該子領地的建造與設定權，租金按週期自動收取，付給「租金收款對象」，預設是領地擁有者。個人商店（見 tokaShop 的 `docs/PLAYER-SHOPS.md`）只是租到的空間裡可以做的事，商店本身不收租金。

## 已有的基礎
`LandClaim` 已有 `parentClaimId`、`inheritOwner`、`inheritPermissions`，權限用「子領地只存差異」解析，所以子領地不需要新的資料模型。租賃只需要加上「租約」。

## 租約（Lease）
附在一塊子領地上，存在 tokaLand 的文件儲存，鍵為子領地 ID：

| 欄位 | 說明 |
|---|---|
| `claimId` | 出租的子領地 |
| `lessor` | 租金收款對象，帳戶 UUID；預設為父領地的實際擁有者，可改為主國庫或其他帳戶 |
| `rent` | 每期租金（整數，貨幣由設定決定） |
| `periodDays` | 週期天數（預設 7） |
| `graceDays` | 欠租寬限天數（預設 3） |
| `state` | `VACANT`（空置、可承租）、`LEASED`、`GRACE`（欠租寬限） |
| `tenant` | 承租人 UUID（`LEASED`、`GRACE` 時才有） |
| `paidUntil` | 已繳到的時間 |
| `deposit` | 押金（可為 0），退租無欠租時退還 |

## 狀態與流程
1. **出租**：領地擁有者在 `/land lease offer <子領地> <租金> [週期天數]`（或領地視窗）把子領地標為 `VACANT`；列入「可承租清單」，視窗與告示牌可看到。
2. **承租**：玩家選擇空置的子領地並確認；扣第一期租金與押金（`withdrawOnce`，操作 ID 含租約與期數，可重試不重複），子領地的擁有者改為承租人（`ownerId` = 承租人、`inheritOwner` = false），狀態 `LEASED`。
3. **續期**：每期到期自動從承租人帳戶扣租金（操作 ID = 租約 ID + 期數），付給 `lessor`；成功則 `paidUntil` 往後一期。
4. **欠租**：餘額不足進入 `GRACE`，通知承租人；寬限內補足即回到 `LEASED`。
5. **收回**：寬限到期或承租人退租，子領地擁有者恢復為繼承（`inheritOwner` = true），租約回到 `VACANT`；承租人留在裡面的物品與設定保留在原地，押金依規則退還或抵扣。
6. **轉租、修改租金**：承租人不能轉租；出租人改租金只影響下一期，並先通知承租人。

## 與其他插件
- **tokaEconomy**：只用既有的 `withdrawOnce` / `depositOnce`，不需要凍結。
- **tokaShop**：承租人在自己的子領地可以開攤位店（第二階段）；稅金照常進主國庫。
- **tokaProfiles**：承租期與欠租寫進玩家備註或 Plan 摘要（選用）。
- **競標**（第三階段）：空置子領地可改為競標，得標價就是該期租金，其餘流程相同。

## 階段
1. 租約資料與指令（出租、承租、退租）、扣款與自動續期、欠租與收回、領地視窗的租賃頁。
2. 可承租清單與告示牌；承租人的攤位店。
3. 競標。

## 需要決定
- 週期（預設 7 天）與寬限（預設 3 天）是否合適。
- 租金貨幣：銀幣（預設）還是也允許金幣。
- 押金是否需要，預設 0。
- 租金收款對象的預設是否為「父領地擁有者」。
