# 領地租賃（下級領地分租）

目標：領地擁有者（或國庫）把自己的一塊領地切成下級領地，出租給其他玩家；承租期間承租人有該下級領地的建造與設定權，租金按週期自動收取，付給「租金收款對象」，預設是領地擁有者。個人商店（見 tokaShop 的 `docs/PLAYER-SHOPS.md`）只是租到的空間裡可以做的事，商店本身不收租金。

## 已有的基礎
`LandClaim` 已有 `parentClaimId`、`inheritOwner`、`inheritPermissions`，權限用「下級領地只存差異」解析，所以下級領地不需要新的資料模型。租賃只需要加上「租約」。

## 租約（Lease）
附在一塊下級領地上，存在 tokaLand 的文件儲存，鍵為下級領地 ID。狀態除下列三種外，還有承租後尚未到起始日的預約（`RESERVED`）：

| 欄位 | 說明 |
|---|---|
| `claimId` | 出租的下級領地 |
| `lessor` | 租金收款對象，帳戶 UUID；預設為上級領地的實際擁有者，可改為主國庫或其他帳戶 |
| `rent` | 一期的租金（整數） |
| `periodDays` | 一期的天數，**預設 90（三個月）**；填 -1 表示**沒有期限**（見下） |
| `maxPeriods` | 承租人一次最多預付幾期，預設 12（三年）；可設更多或 1 |
| `graceDays` | 欠租寬限天數（預設 7） |
| `state` | `VACANT`（空置、可承租）、`LEASED`、`GRACE`（欠租寬限） |
| `tenant` | 承租人 UUID |
| `startAt` | 租期開始時間，**預設是承租的當下**；可以設成之後的日期（到期前下級領地仍屬出租人） |
| `endAt` | 租期結束時間，**預設是開始後一個週期再加一天**（週期 90 天就是 91 天，多的一天是續租緩衝）；可以改成指定日期；沒有期限的租約沒有這個值 |
| `paidUntil` | 已繳到的時間 |
| `autoRenew` | 到期時是否自動續一期（預設開） |
| `deposit` | 押金，預設 0 |

## 租期的幾種用法
- **一般週期租**：`periodDays` 90，承租人預付 1 期；到期自動續一期（`autoRenew`），餘額不足進入寬限。
- **一次付清多期**：承租人承租時選擇期數，例如 4 期（一年）、12 期（三年），一次扣款，期滿前不再扣；期滿可自動續一期，或回到空置。長租可以設折扣（`discount`：預付超過 N 期時每期打幾折，預設不打折）。
- **沒有租期限制**：`periodDays: -1`。租金只在承租時收一次，之後沒有到期日，不再扣款，承租人可以一直使用，直到自己退租或出租人依規定收回（例如承租人帳號被封禁）。這等於買斷使用權，租金請訂得像一筆小額購買。

## 起訖日
出租時或承租時可以指定起始日與終止日：
- 只填起始日：從該日開始，到「起始日 + 一個週期 + 一天」。
- 填了終止日：到該日結束；預付的期數不能超過終止日，超過的部分不收、不退。
- 都不填：從承租當下開始，到一個週期加一天。
- 起始日還沒到時，下級領地仍屬出租人，扣款在起始日當天才進行；起始日前承租人可以取消，全額退還。

## 狀態與流程
1. **出租**：擁有者用 `/land lease offer <下級領地> <租金> [期天數]`（或領地詳細視窗的出租按鈕）把下級領地標為 `VACANT`，列入可承租清單。
2. **承租**：玩家選擇空置的下級領地與期數，確認總額後扣款（`withdrawOnce`，操作 ID 含租約、期數起點，可重試不重複），下級領地擁有者改為承租人（`ownerId` = 承租人、`inheritOwner` = false），狀態 `LEASED`。
3. **續期**：有期限的租約，期滿前依 `autoRenew` 從承租人帳戶扣下一期租金，付給 `lessor`；成功則 `paidUntil` 往後一期。
4. **欠租**：餘額不足進入 `GRACE`，通知承租人；寬限內補足回到 `LEASED`。
5. **收回**：寬限到期、承租人退租、或沒有期限的租約被依規定收回，擁有者恢復為繼承（`inheritOwner` = true），租約回到 `VACANT`；承租人留在裡面的物品與設定保留在原地，押金依規則退還或抵扣。預付的剩餘期數不退（退租前會提醒）。
6. **轉租、修改租金**：承租人不能轉租；出租人改租金只影響下一期，並先通知承租人。

## 下級領地的權限（現有規則，租賃沿用）
不是疊加，是「子層優先、沒寫就繼承」：從下級領地往上找，第一個對這個人、這項權限明確寫了允許或拒絕的就算數；下級領地沒寫才看上級領地（前提是下級領地的 `inheritPermissions` 為 true）。下級領地的擁有者永遠允許。
- 租賃開始時，下級領地改為 `inheritPermissions = false`：承租人自己決定誰能進來，上級領地成員清單不會滲進他的空間；出租人不會自動擁有進入權，但保有收回的權利。
- 收回後恢復為繼承，承租人寫的允許與拒絕一併清除。

## 與其他插件
- **tokaEconomy**：只用既有的 `withdrawOnce` / `depositOnce`，不需要凍結。
- **tokaShop**：承租人在自己的下級領地可以開攤位店（尚未提供）；稅金照常進主國庫。
- **tokaProfiles**：承租期與欠租寫進玩家備註或 Plan 摘要（選用）。

## 指令與視窗
`/land lease offer|set|cancel|rent|release|info|list`。領地視窗的詳細頁有「建立下級領地」與「出租」按鈕，租賃選單列出可承租的下級領地與自己的租約；承租人在詳細頁可看租約並退租。

## 預設值
設定在 tokaLand 的 `lease:` 區段：貨幣、一期天數（90）、預付上限期數（12）、寬限天數（7）、起訖日時區、`allow-perpetual`（預設 false，開啟後出租人才能選沒有期限的租約）。折扣、押金與租金收款對象由出租人在租約上設定；收款對象預設是上級領地的實際擁有者。

## 之後
承租人的攤位店（見 tokaShop 的 `docs/PLAYER-SHOPS.md`）與競標：空置的下級領地改為競標，得標價就是該期租金，其餘流程相同。
